# High-Speed Pipelined Vedic Multiplier

## Overview
Verilog implementation of a Vedic multiplier using recursive arithmetic architecture, Carry-Save Adders (CSA), and a Kogge–Stone Adder (KSA).

## Features
- Verilog RTL implementation
- Recursive multiplier architecture
- Carry-Save Adder-based partial-product reduction
- Kogge–Stone final adder
- FPGA implementation using Xilinx Vivado

## Source Files
- `vedic.v` — Main multiplier and supporting RTL modules
- `top_arty.v` — Top-level FPGA module

## Tools
- Verilog HDL
- Xilinx Vivado
